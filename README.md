# Pablo Muñoz · vista previa del inicio

Vista previa de la página de inicio de pablomunozchef.com: dirección culinaria y gastronomía de autor.
Diseño de Neris Studio. La página no se indexa en buscadores (`noindex`).

- `index.html`: página completa.
- `img/`: fotos a resolución completa (2560 px, WebP) más una versión de 1400 px para móvil, que el navegador elige solo (`srcset`), y los vídeos.
